# Securing AI agents in the Microsoft ecosystem

A single-page reference map of the protection mechanisms for AI agents across Microsoft Agent 365, Entra, Defender, Purview, Foundry and Copilot Studio. Each item carries a link icon to the matching Microsoft Learn page.

Static site: plain HTML and CSS, no build step. All paths are relative, so it works at `https://<user>.github.io/<repo>/`.

## Publish on GitHub Pages

1. Create a repository and push these files to the `main` branch root.
2. In **Settings > Pages**, set **Source** to **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Open `https://<user>.github.io/<repo>/` after the first deploy finishes.

## Edit

- Content: `index.html`
- Look: `assets/style.css`
